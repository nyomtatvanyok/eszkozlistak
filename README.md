# Bolti dokumentumtár

https://nyomtatvanyok.github.io/eszkozlistak/

A boltok felülvizsgálati dokumentumai és eszközei (csak betekintés és letöltés). Az adatokat az oldal minden megnyitáskor
élőben kéri le a „Bolti dokumentumtár” Apps Script webalkalmazástól (`?api=` JSON-végpont), így a táblázat
minden módosítása azonnal látszik. Egy bolt közvetlen linkje: `?bolt=<bolt neve>`.

Az `index.html` generált fájl (`tools/github_eszkozlistak.js`, az Apps Script `Oldal.html`-jéből) – ne kézzel szerkeszd.
